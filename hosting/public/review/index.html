Why this design

Controls before automation

  • 01Permission is explicit. A preflight shows engine, provider, model, reference version, tolerances and warnings before any file is processed.
  • 02Extraction is separate from approval. Field completeness is read coverage; validation and human review determine correctness and export readiness.
  • 03Exceptions stop safely. Missing identity, quantity, price, receipt or tax evidence stays held for correction.
  • 04The source stays visible. Reviewers compare the original document with editable values and provenance.
  • 05Urgency is explicit. Manual download exposes every target field but is labelled unvalidated and reserves no receipt.

Security posture

Data boundaries

  • Non-GET requests require a same-origin studio header; every cloud API route requires owner authentication.
  • Uploads are bounded by type, size and page/frame limits.
  • API keys and setup tokens stay encrypted server-side and absent from state responses; saved and provider-verified states are distinct.
  • Reader subprocesses do not receive provider secrets.
  • Managed Vertex uses the workspace service identity and project billing; no user API key is stored.
  • Claude receives required extracted text with tools disabled and a restricted environment.
  • ChatGPT export removes the local encrypted credential and active selection before hosted import.
  • Confirmed deletion removes live evidence; minimal ledger tombstones remain and provider backups/versions follow provider retention.

Decisions that shape the MVP

Lookup separate from approvalLets operators search real sources using identifiers, names and commercial clues.Candidate rank requires explicit human confirmation and steward follow-up.
Manual draft separate from exportUrgent entry can continue during OCR without consuming receipts or changing the job.The receiving process must respect the prominent unvalidated label.
